# Employee Perfume Review Portfolio

员工香评录入产品的脱敏领域模型，演示香水搜索、重复提交确认、覆盖后重置 AI 状态、匿名身份映射与共识聚合。

> 这是作品集重构版，不是线上应用仓库。样例不包含员工信息、飞书 App/Table ID、访问令牌、组织域名或生产代码。

## 原项目中的产品取舍

- 员工只填写香水与香评正文，产品编号和活动来源由系统回填。
- 同一填写人重复评价同一香水时必须先确认覆盖。
- 覆盖旧记录后将 AI 状态重置为 `PENDING_AI`，避免沿用过期结果。
- 主提交成功优先于辅助人员字段回填，降低非核心依赖导致的失败。
- 共识只由已审核数据计算，模型生成内容不能替代原始评价。

## 运行

需要 Node.js 18+：

```bash
npm test
node review_domain.mjs sample_data.json
```

真实应用使用 React、NestJS、TypeScript 与协同办公平台。本仓库使用零依赖 Node.js 参考模型展示可复用规则，便于安全审阅。
